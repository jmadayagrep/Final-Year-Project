# 🌍 Final Year Project — Business Intelligence & GIS for Disaster Management

## 📘 Overview

This repository contains my final year dissertation exploring how **Business Intelligence (BI)** and **Geographical Information Systems (GIS)** can address two critical challenges in disaster management:

* ⏱️ **Delayed emergency response**
* 📦 **Inefficient resource allocation**

Through qualitative analysis of real-world case studies, this project demonstrates how data-driven technologies can support **proactive disaster preparedness**, **faster decision-making**, and **smarter distribution of resources** in disaster-prone regions.

---

## 🎯 Research Aim

The goal of this project was to investigate how BI tools and GIS systems can:

* Improve disaster response time
* Optimise allocation of emergency resources
* Support predictive decision-making before disasters occur
* Enhance coordination between disaster agencies

The research bridges **data analytics**, **spatial analysis**, and **decision support systems** in the context of disaster management.

## 🔍 Case Studies

### 🇹🇭 BI Framework — Phuket, Thailand

A conceptual Business Intelligence model was analyzed to show how disaster data can be:

* Collected from multiple sources
* Cleaned and processed through ETL pipelines
* Stored in a multidimensional data warehouse
* Analyzed using OLAP tools
* Visualized through dashboards

This approach enabled identification of **high-risk flood and landslide zones**, supporting predictive disaster planning and prioritization of vulnerable regions.

---

### 🇮🇳 GIS System — Allahabad Sadar, India

A GIS-based flood disaster management system was examined using ArcView mapping. The system produced thematic maps of:

* Road infrastructure (mud vs paved roads)
* Healthcare facility access
* Relief camp routes
* Population distribution

These spatial insights allowed authorities to:

* Prioritize inaccessible or high-risk villages
* Plan evacuation and supply routes
* Improve emergency medical response
* Support strategic infrastructure planning

---

## ✅ Key Findings

The research highlights several important outcomes:

* BI systems transform raw disaster data into actionable insights
* GIS enables powerful visualization of vulnerable areas
* Combining BI + GIS supports proactive disaster planning
* Data-driven prioritization improves response efficiency
* Visual dashboards enhance inter-agency communication

Overall, integrating BI and GIS can significantly reduce response delays and improve survival outcomes in disaster scenarios.
